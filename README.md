## English

### About this project

This repository contains practical learning notes on biostatistics and machine learning for health, social, and behavioral sciences. The material emphasizes reproducible analysis, careful interpretation, transparent model evaluation, and responsible use.

The published editions are standalone English HTML pages. They can be opened directly in a browser and do not require R, Python, or a web server.

### Published guides

| Guide | Main topics | Open |
|---|---|---|
| Practical Biostatistics with R | Study design, probability, inference, regression, ANOVA, nonparametric methods, power, and survival analysis | [Open the biostatistics guide](biostatistics_guide_en.html) |
| High-Dimensional Regression Modeling | Regularization, variable selection, validation, stability, interpretation, and reproducible analysis | [Open the high-dimensional regression guide](high_dimensional_regression_guide_en.html) |
| Supervised Machine Learning in Sociology and Psychology | Classification, regression, validation, calibration, interpretability, fairness, and reproducible R/Python examples | [Open the supervised learning guide](supervised_ml_social_psychology_en.html) |
| Unsupervised Machine Learning in Sociology and Psychology | Clustering, dimensionality reduction, latent structure, evaluation, interpretation, and applied R/Python examples | [Open the unsupervised learning guide](unsupervised_ml_social_psych_en.html) |

### Intended audience

- Students and researchers in biostatistics, sociology, psychology, public health, and related fields;
- Readers learning applied R or Python workflows;
- Analysts who want prediction and inference to remain aligned with study design, measurement quality, uncertainty, and ethics.

### Responsible-use note

The datasets and examples are educational. They must not be used directly for clinical diagnosis, treatment decisions, denial of services, employment, criminal justice, or other high-impact decisions. Real applications require appropriate domain review, privacy safeguards, external validation, and ongoing monitoring.

### Repository policy

Rendered English HTML pages and this README are intended for publication. R Markdown source files, Chinese HTML editions, local reference materials, and R session files are excluded through `.gitignore`.

## Français

### À propos de ce projet

Ce dépôt rassemble des notes pratiques sur la biostatistique et l’apprentissage automatique appliqués aux sciences de la santé, aux sciences sociales et aux sciences du comportement. Le contenu met l’accent sur la reproductibilité, l’interprétation prudente, l’évaluation transparente des modèles et leur utilisation responsable.

Les versions publiées sont des pages HTML autonomes en anglais. Elles peuvent être ouvertes directement dans un navigateur, sans installation de R, de Python ni de serveur web.

### Guides publiés

### Public visé

- Étudiantes, étudiants et chercheurs en biostatistique, sociologie, psychologie, santé publique et disciplines connexes ;
- Personnes qui apprennent des méthodes appliquées avec R ou Python ;
- Analystes souhaitant relier la prédiction et l’inférence au plan d’étude, à la qualité des mesures, à l’incertitude et à l’éthique.

### Utilisation responsable

Les données et les exemples sont destinés à l’apprentissage.
